Smart Cart – Customer Segmentation Using Machine Learning

Project Overview

Smart Cart is a Machine Learning project focused on customer segmentation using unsupervised learning techniques. The project analyses customer demographics, income, purchasing behaviour, and spending patterns to identify different customer groups.

Objectives

- Identify different customer segments based on purchasing behaviour.
- Analyse customer income and spending patterns.
- Apply dimensionality reduction using PCA.
- Determine optimal clusters using the Elbow Method and Silhouette Score.
- Compare K-Means and Agglomerative Clustering algorithms.

Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Exploratory Data Analysis (EDA)
5. Outlier Detection and Treatment
6. Categorical Feature Encoding
7. Feature Scaling using StandardScaler
8. Dimensionality Reduction using PCA
9. Optimal Cluster Selection
10. K-Means Clustering
11. Agglomerative Clustering
12. Customer Segmentation Analysis

Machine Learning Algorithms

- K-Means Clustering
- Agglomerative Hierarchical Clustering
- Principal Component Analysis (PCA)

Key Results

- Processed 2,236 customer records after outlier removal.
- Identified 4 optimal clusters using the Elbow Method.
- Evaluated clustering quality using Silhouette Score.
- Compared customer segments based on income, spending, and purchasing behaviour.

Project Files

- "smart_cart.csv" – Customer dataset.
- "smart_cart.ipynb" – Jupyter Notebook containing data analysis and machine learning implementation.

Conclusion

This project demonstrates how unsupervised machine learning techniques can be used to understand customer behaviour, identify meaningful customer segments, and support data-driven marketing strategies.
